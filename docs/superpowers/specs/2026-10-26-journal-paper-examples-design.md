# 每刊精选论文实例设计

## 目的

在现有投稿工作台中，为 17 本期刊各提供 3 篇真实已发表论文，帮助金属材料/高熵合金研究者观察该刊如何组织摘要、主图、机制证据和参考文献，而不是把示意图或通用建议当作实例。

## 范围与边界

- 每刊恰好 3 篇，优先金属材料、高熵/中熵合金、结构材料和力学机制论文。
- 每篇包含题名、年份、文章类型、主题、DOI/出版社正式链接、推荐理由和建议观察点。
- 实例独立显示为“精选已发表实例”，不混入“官方模板与实例”；已发表论文只用于观察呈现，不代表期刊强制模板或编辑推荐。
- 不抓取论文图片，不转载全文，不展示不稳定的引用次数。
- 所有链接使用 `https://doi.org/...` 或出版社正式页面；同一 DOI 不得在同一期刊重复。

## 方案

考虑过三种方式：直接扩充现有 `resources`、把实例写死在 `app.py`、新建独立数据层。采用独立 `journal_examples.yaml`：它能严格校验 17×3 的覆盖和 DOI 唯一性，不会把“官方模板”与“已发表论文”混淆，后续也便于单独更新实例。

## 页面呈现

在“官方模板与实例”之后插入“精选已发表实例”。每篇用紧凑卡片显示题名链接、年份/文章类型/主题徽标，以及“为什么选”和“重点观察”两段。移动端保持单列，桌面端三列。

## 验证

- 数据测试：17 本期刊全部覆盖、每刊 3 篇、字段完整、年份合法、HTTPS DOI/出版社链接、期刊内 URL 唯一。
- 内容测试：Nature、Science、Acta Materialia 等代表性 DOI 与题名准确。
- UI 测试：选择期刊后可看到新标题、3 篇实例、链接和观察建议，旧模块仍保留。
- 全量回归、本地 Streamlit 渲染、线上公开验证器均通过后发布。
